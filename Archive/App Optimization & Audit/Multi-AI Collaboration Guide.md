# 🤖 Multi-AI Collaboration Guide (Manager System)

This guide defines the workflow for solving complex problems using multiple different AI models collaborating through a shared document.

---

## 💡 System Context & Concept
The goal is to get multiple diverse viewpoints on any topic by running it through different AI models (e.g., Gemini Flash, Claude, DeepSeek, GPT). Each model has unique strengths and thinking styles. They are given ample time to think and analyze before answering. Their responses are compiled by a Manager AI into a short, simple, and direct summary with a final conclusion.

---

## 👥 Roles & Responsibilities

### 1. The Manager AI (Coordinator & Summarizer)
* **Role**: The main organizer and final consolidator.
* **Tasks**:
  * **Generate Prompts**: Create copy-paste prompts tailored for different AI models to address the topic.
  * **Compile Opinions**: Read the shared Obsidian document containing all Specialist answers.
  * **Simplify & Summarize**: Condense long, detailed specialist answers into a short, beginner-friendly summary.
  * **Provide Conclusion**: Offer a final unified conclusion/recommendation based on all inputs.

### 2. The Specialist AIs (The Diverse Thinkers)
* **Role**: Different AI models (e.g., Gemini 3.5 Flash, Claude 3.5 Sonnet, DeepSeek) providing unique angles.
* **Tasks**:
  * **Deep Analysis**: Analyze the prompt calmly, peacefully, and deeply without rushing.
  * **Write Input**: 
    * Coding agents (like Antigravity/Kiro) write their answers directly to this shared Obsidian file.
    * Chat-based bots provide text for the user to copy-paste manually into the file.

---

## 🔄 Collaboration Workflow

```
[User Input Topic]
       │
       ▼
[Manager AI] ➔ Generates specialist prompts
       │
       ▼
[Specialist AIs] ➔ Think deeply & write answers to this file
       │
       ▼
[Manager AI] ➔ Compiles answers, simplifies them, and gives final conclusion
```

1. **Initiation**: The user tells the Manager AI a topic or problem to discuss.
2. **Prompt Creation**: The Manager AI creates a customized prompt.
3. **Execution**: The user sends the prompt to the different Specialist models.
4. **Data Collection**: All specialist responses are saved in the designated section below or in a shared file.
5. **Final Review**: The Manager AI reads the responses, simplifies them into a short, easy-to-understand summary, and outputs the final verdict.
